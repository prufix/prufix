## Definition

BT-24, the **specification identifier**, is the URN that states which exact
version of which specification the document claims to follow (plain EN
16931, or a CIUS/extension built on top of it such as Peppol BIS or
XRechnung). Every EN 16931-conformant document must declare it, because
every other rule in this dictionary is only meaningful relative to a
declared specification.

## Common causes

- **The element is entirely absent** because the generating code was built
  against a plain UBL/CII template that never had it, rather than an
  EN 16931 one.
- **Wrong specification value for the target profile.** The element exists
  but holds the plain EN 16931 URN
  (`urn:cen.eu:en16931:2017`) when the document is actually meant to be
  submitted as Peppol BIS Billing 3.0, which requires the extended value —
  see `PEPPOL-EN16931-R004` for that specific mismatch.
- **Placed in the wrong position or wrong element** — in UBL this must be
  the value of `cbc:CustomizationID`, not `cbc:ProfileID` (which is BT-23,
  the business process, checked separately by `PEPPOL-EN16931-R001`); the two
  are easy to conflate since they're adjacent, both are URNs, and both are
  near the top of the document.

## How to fix it

- **UBL**: add `cbc:CustomizationID` as the first business element of the
  document (immediately after `UBLVersionID`), with value
  `urn:cen.eu:en16931:2017` for plain EN 16931, or
  `urn:cen.eu:en16931:2017#compliant#urn:fdc:peppol.eu:2017:poacc:billing:3.0`
  for Peppol BIS Billing 3.0.
- **CII**: add `ram:GuidelineSpecifiedDocumentContextParameter/ram:ID` under
  `rsm:ExchangedDocumentContext`, value `urn:cen.eu:en16931:2017`.

## Example

### UBL — wrong

```xml
<Invoice xmlns="urn:oasis:names:specification:ubl:schema:xsd:Invoice-2" ...>
  <cbc:UBLVersionID>2.1</cbc:UBLVersionID>
  <!-- CustomizationID missing -->
  <cbc:ID>INV-2026-0001</cbc:ID>
  ...
</Invoice>
```

### UBL — correct

```xml
<Invoice xmlns="urn:oasis:names:specification:ubl:schema:xsd:Invoice-2" ...>
  <cbc:UBLVersionID>2.1</cbc:UBLVersionID>
  <cbc:CustomizationID>urn:cen.eu:en16931:2017</cbc:CustomizationID>
  <cbc:ID>INV-2026-0001</cbc:ID>
  ...
</Invoice>
```

### CII — correct

```xml
<rsm:ExchangedDocumentContext>
  <ram:GuidelineSpecifiedDocumentContextParameter>
    <ram:ID>urn:cen.eu:en16931:2017</ram:ID>
  </ram:GuidelineSpecifiedDocumentContextParameter>
</rsm:ExchangedDocumentContext>
```
