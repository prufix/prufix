## Definition

Every invoice line must name the item or service being billed (BT-153).
Unlike header-level "missing field" rules (`BR-01`–`BR-06`), this one is
checked **per line**, so a single invoice with 40 lines and one blank
description fails once, on that one line.

## Common causes

- **Free-text/miscellaneous lines** (shipping, adjustments, rounding) added
  by code that populates amounts and tax category but skips the name field
  because "it's not really a product".
- **Item name pulled from a catalog lookup that returned nothing** (a
  discontinued SKU, a bad product ID) — the amount and quantity are still
  populated from cached values, so the line looks otherwise complete and the
  missing name is easy to miss without validation.
- **Name present but empty after trimming** — a template renders
  `<cbc:Name>{{item.description}}</cbc:Name>` and the description field was
  whitespace-only or null, serializing as an empty element rather than
  failing the generation step.

## How to fix it

- **UBL**: add `cac:Item/cbc:Name` to the line
  (`cac:InvoiceLine` or `cac:CreditNoteLine`), non-empty.
- **CII**: add `ram:SpecifiedTradeProduct/ram:Name` to the line item's
  `ram:IncludedSupplyChainTradeLineItem`.

## Example

### UBL — wrong

```xml
<cac:InvoiceLine>
  <cbc:ID>3</cbc:ID>
  <cbc:InvoicedQuantity unitCode="C62">1</cbc:InvoicedQuantity>
  <cbc:LineExtensionAmount currencyID="EUR">25.00</cbc:LineExtensionAmount>
  <cac:Item>
    <!-- Name missing -->
    <cac:ClassifiedTaxCategory>
      <cbc:ID>S</cbc:ID>
      <cbc:Percent>19</cbc:Percent>
    </cac:ClassifiedTaxCategory>
  </cac:Item>
</cac:InvoiceLine>
```

### UBL — correct

```xml
<cac:InvoiceLine>
  <cbc:ID>3</cbc:ID>
  <cbc:InvoicedQuantity unitCode="C62">1</cbc:InvoicedQuantity>
  <cbc:LineExtensionAmount currencyID="EUR">25.00</cbc:LineExtensionAmount>
  <cac:Item>
    <cbc:Name>Shipping and handling</cbc:Name>
    <cac:ClassifiedTaxCategory>
      <cbc:ID>S</cbc:ID>
      <cbc:Percent>19</cbc:Percent>
    </cac:ClassifiedTaxCategory>
  </cac:Item>
</cac:InvoiceLine>
```

### CII — correct

```xml
<ram:IncludedSupplyChainTradeLineItem>
  <ram:SpecifiedTradeProduct>
    <ram:Name>Shipping and handling</ram:Name>
  </ram:SpecifiedTradeProduct>
</ram:IncludedSupplyChainTradeLineItem>
```
