## Definition

BT-5, the document currency code, states the currency the invoice is
denominated in as a whole. It must be present. This rule only checks that
the code exists; whether it's a valid ISO 4217 code is checked separately by
`BR-CL-04`.

## Common causes

- **`currencyID` attributes present on amounts, but no document-level
  `DocumentCurrencyCode`.** UBL repeats `currencyID` as an attribute on
  every monetary amount (`<cbc:TaxExclusiveAmount currencyID="EUR">`), which
  can create the impression that the currency is "already stated" — but BT-5
  is a separate, single, mandatory header element; the per-amount attributes
  don't substitute for it.
- **Multi-currency systems that default the header currency from the
  operating/base currency**, not the currency the invoice is actually issued
  in, and then skip serializing it when the two happen to be undetermined.
- **CII placement mistake**: the currency code is written somewhere else in
  the document (e.g. only on the tax accounting currency, BT-6) instead of
  under `ApplicableHeaderTradeSettlement` as `InvoiceCurrencyCode`.

## How to fix it

- **UBL**: add `cbc:DocumentCurrencyCode` with an ISO 4217 alpha-3 code
  (e.g. `EUR`) as a direct header element — separate from, and in addition
  to, the `currencyID` attributes on individual amounts.
- **CII**: add `ram:InvoiceCurrencyCode` under
  `ram:ApplicableHeaderTradeSettlement`, with an ISO 4217 code.

## Example

### UBL — wrong

```xml
<Invoice ...>
  <cbc:ID>INV-2026-0001</cbc:ID>
  <!-- DocumentCurrencyCode missing -->
  <cac:LegalMonetaryTotal>
    <cbc:TaxExclusiveAmount currencyID="EUR">1180.00</cbc:TaxExclusiveAmount>
  </cac:LegalMonetaryTotal>
</Invoice>
```

### UBL — correct

```xml
<Invoice ...>
  <cbc:ID>INV-2026-0001</cbc:ID>
  <cbc:DocumentCurrencyCode>EUR</cbc:DocumentCurrencyCode>
  <cac:LegalMonetaryTotal>
    <cbc:TaxExclusiveAmount currencyID="EUR">1180.00</cbc:TaxExclusiveAmount>
  </cac:LegalMonetaryTotal>
</Invoice>
```

### CII — correct

```xml
<ram:ApplicableHeaderTradeSettlement>
  <ram:InvoiceCurrencyCode>EUR</ram:InvoiceCurrencyCode>
  ...
</ram:ApplicableHeaderTradeSettlement>
```
